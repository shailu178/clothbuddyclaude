# 📱 ClothBuddy — Complete Beginner's Deployment Guide
# Zero experience needed. Follow every step in order.
# Estimated time: 45–60 minutes

═══════════════════════════════════════════════════════════
WHAT WE ARE DOING (simple version)
═══════════════════════════════════════════════════════════

  Your App (the .jsx file)
       ↓
  We put it on the internet (Vercel) ← people visit this
       ↓
  It talks to a secret server (Railway) ← hides your API key
       ↓
  That server talks to Claude (Anthropic)

At the end you get a real website link like:
  https://clothbuddy.vercel.app

Anyone can open it on their phone and tap
"Add to Home Screen" — it works like a real app!

═══════════════════════════════════════════════════════════
WHAT YOU NEED BEFORE STARTING
═══════════════════════════════════════════════════════════

  ✓ A computer (Mac or Windows, both work)
  ✓ Internet connection
  ✓ An email address
  ✓ The clothbuddy-pwa.zip file (you already have this)
  ✓ About 45-60 minutes

═══════════════════════════════════════════════════════════
PHASE 1 — INSTALL TOOLS ON YOUR COMPUTER (15 minutes)
═══════════════════════════════════════════════════════════

──────────────────────────────────────────────────────────
STEP 1 — Install Node.js
──────────────────────────────────────────────────────────

Node.js lets your computer run JavaScript code.
You NEED this. Without it nothing works.

  1. Open your web browser
  2. Go to:  https://nodejs.org
  3. You will see a big green button that says "LTS"
     (it will show a number like 20.x.x or 22.x.x)
  4. Click that green LTS button → it downloads a file
  5. Open the downloaded file and click through the installer
     → Click "Next" on every screen
     → Accept the agreement
     → Keep all default settings
     → Click "Install"
     → Click "Finish"

  HOW TO CHECK IT WORKED:
  - On Mac: Open "Terminal" app
    (press Cmd+Space, type Terminal, press Enter)
  - On Windows: Open "Command Prompt"
    (press Windows key, type "cmd", press Enter)

  Type this and press Enter:
    node --version

  You should see something like:  v22.0.0
  If you see a version number → ✅ Node.js is installed!
  If you see an error → restart your computer and try again.

──────────────────────────────────────────────────────────
STEP 2 — Install Git
──────────────────────────────────────────────────────────

Git lets you upload your code to the internet.

  Mac users:
    Type this in Terminal and press Enter:
      git --version
    If it shows a version number, you already have it! Skip to Step 3.
    If not, go to: https://git-scm.com/download/mac
    Download and install it.

  Windows users:
    Go to: https://git-scm.com/download/win
    Download the installer, run it, click Next on everything.

  HOW TO CHECK:
    Type in Terminal/Command Prompt:
      git --version
    Should show something like: git version 2.x.x  ✅

──────────────────────────────────────────────────────────
STEP 3 — Install VS Code (code editor — optional but helpful)
──────────────────────────────────────────────────────────

  Go to: https://code.visualstudio.com
  Download and install it.
  This is just a text editor that makes code easier to read.
  You don't NEED this but it helps.

═══════════════════════════════════════════════════════════
PHASE 2 — SET UP YOUR PROJECT FOLDER (10 minutes)
═══════════════════════════════════════════════════════════

──────────────────────────────────────────────────────────
STEP 4 — Unzip your project
──────────────────────────────────────────────────────────

  1. Find the file:  clothbuddy-pwa.zip
     (you downloaded this from Claude)

  2. Unzip it:
     - On Mac: Double-click the zip file
     - On Windows: Right-click → "Extract All" → Click Extract

  3. You now have a folder called "clothbuddy"
     Move it somewhere easy to find, like your Desktop.

  Your folder should look like this inside:
    clothbuddy/
      src/
        App.jsx      ← your app
        main.jsx
        api.js
      server/
        index.js     ← backend server
        package.json
      public/
        favicon.svg
      package.json
      vite.config.js
      DEPLOY.md
      .env.example
      ... other files

──────────────────────────────────────────────────────────
STEP 5 — Open Terminal IN your project folder
──────────────────────────────────────────────────────────

  This is important — you must be INSIDE the clothbuddy folder.

  Mac:
    1. Open Terminal
    2. Type:  cd Desktop/clothbuddy
       (if you put it somewhere else, adjust the path)
    3. Press Enter

  Windows:
    1. Open the clothbuddy folder in File Explorer
    2. Click on the address bar at the top (where it shows the path)
    3. Type "cmd" and press Enter
    → A Command Prompt opens already inside that folder!

  HOW TO CHECK YOU'RE IN THE RIGHT PLACE:
    Type:  ls    (Mac) or  dir    (Windows)
    You should see files like package.json, vite.config.js, etc.

──────────────────────────────────────────────────────────
STEP 6 — Install project dependencies
──────────────────────────────────────────────────────────

  These commands download all the code libraries the app needs.
  Make sure you're in the clothbuddy folder (Step 5).

  Type this and press Enter (wait for it to finish — takes 1-2 minutes):
    npm install

  You'll see lots of text scrolling. That's normal.
  Wait until you see your cursor blinking again.

  Now install the server dependencies:
    cd server
    npm install
    cd ..

  ✅ When done, you're back in the clothbuddy folder.

PHASE 3 — CREATE YOUR FREE ACCOUNTS (10 minutes)
══════════════════════════════════════════════════════════

You need 3 free accounts. Open these in your browser:

──────────────────────────────────────────────────────────
STEP 7 — Create a GitHub account
──────────────────────────────────────────────────────────

  GitHub stores your code online. It's free.

  1. Go to: https://github.com
  2. Click "Sign up"

STEP 9 — Create a Railway account
──────────────────────────────────────────────────────────

  Railway runs your backend server. It's free for small apps.

  1. Go to: https://railway.app

  3. Click "Login with GitHub"
  4. Authorize Railway
  ✅ You have a Railway account!

══════════════════════════════════════════════════════════
PHASE 4 — GET YOUR ANTHROPIC API KEY (5 minutes)
══════════════════════════════════════════════════════════

──────────────────────────────────────────────────────────
STEP 10 — Get your API key
──────────────────────────────────────────────────────────

  The API key lets your app use Claude AI.
  You MUST have this — the app won't work without it.

  1. Go to: https://console.anthropic.com
  2. Sign up or log in
  3. Click "API Keys" in the left menu
  4. Click "Create Key"
  5. Give it a name like "clothbuddy"
  6. COPY the key — it starts with "sk-ant-..."

  ⚠️  IMPORTANT: Save this key somewhere safe RIGHT NOW.
      You can only see it once!
      Paste it in a Notes app or text file temporarily.

  The key looks like:
    sk-ant-api03-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

══════════════════════════════════════════════════════════
PHASE 5 — CONFIGURE YOUR APP (5 minutes)
══════════════════════════════════════════════════════════

──────────────────────────────────────────────────────────
STEP 11 — Create your .env file
──────────────────────────────────────────────────────────

  The .env file holds your secret API key.
  This file NEVER gets uploaded to the internet.

  In your Terminal (make sure you're in the clothbuddy folder):

    Mac:
      cp .env.example .env

    Windows:
      copy .env.example .env

  Now open the .env file:
    - If you have VS Code: type  code .env
    - Otherwise open it with Notepad (Windows) or TextEdit (Mac)

  You'll see this:
    ANTHROPIC_API_KEY=sk-ant-...your-key-here...

  Replace "sk-ant-...your-key-here..." with your ACTUAL key from Step 10.
  It should look like:
    ANTHROPIC_API_KEY=sk-ant-api03-xxxxxxxxxxxxx

  Save the file. Close it.

══════════════════════════════════════════════════════════

──────────────────────────────────────────────────────────
STEP 12 — Run the app on your computer
──────────────────────────────────────────────────────────

  Let's make sure everything works before putting it online.

  In Terminal (in your clothbuddy folder), type:

  You'll see output like:

    VITE v5.x.x  ready in 500 ms

  NOW:
  1. Open your web browser
  2. Go to:  http://localhost:5173
  3. You should see the ClothBuddy onboarding screen! 🎉

  Test it:
  - Go through onboarding
  - Try generating an outfit
  - Try the weather card

  If it works → ✅ Your app is working!

  To stop it: press Ctrl+C in Terminal

══════════════════════════════════════════════════════════
PHASE 7 — PUT IT ON GITHUB (5 minutes)
══════════════════════════════════════════════════════════

──────────────────────────────────────────────────────────
STEP 13 — Create a GitHub repository
──────────────────────────────────────────────────────────

  1. Go to: https://github.com
  2. Click the "+" button in the top right
  3. Click "New repository"
  4. Repository name: clothbuddy
  5. Keep it "Public" (required for free Vercel)
  6. DO NOT check "Add a README file"
  7. Click "Create repository"

  You'll see a page with setup instructions.
  Copy the URL that looks like:
    https://github.com/YOURUSERNAME/clothbuddy.git

──────────────────────────────────────────────────────────
STEP 14 — Upload your code to GitHub
──────────────────────────────────────────────────────────

  In Terminal (in your clothbuddy folder), run these
  commands ONE AT A TIME, pressing Enter after each:

    git init
    git add .
    git commit -m "Initial ClothBuddy PWA"
    git branch -M main
    git remote add origin https://github.com/YOURUSERNAME/clothbuddy.git
    git push -u origin main

  ⚠️ Replace YOURUSERNAME with your actual GitHub username!

  It will ask for your GitHub username and password.
  For password: you need a Personal Access Token, not your real password.

  HOW TO GET A PERSONAL ACCESS TOKEN:
  1. Go to github.com → click your profile picture → Settings
  2. Scroll down → click "Developer settings" (bottom left)
  3. Click "Personal access tokens" → "Tokens (classic)"
  4. Click "Generate new token (classic)"
  5. Give it a name, set expiration to 1 year
  6. Check the "repo" checkbox
  7. Click "Generate token"
  8. COPY the token (starts with ghp_...)
  9. Use this as your password when git asks

  When done, go to github.com/YOURUSERNAME/clothbuddy
  You should see all your files there! ✅

══════════════════════════════════════════════════════════
PHASE 8 — DEPLOY BACKEND TO RAILWAY (5 minutes)
══════════════════════════════════════════════════════════

──────────────────────────────────────────────────────────
STEP 15 — Deploy your server to Railway
──────────────────────────────────────────────────────────

  Railway runs the backend that hides your API key.

  1. Go to: https://railway.app
  2. Click "New Project"
  3. Click "Deploy from GitHub repo"
  4. Find and click "clothbuddy"
  5. Railway starts deploying automatically

  NOW ADD YOUR API KEY:
  6. Click on your project
  7. Click on the service that appeared
  8. Click "Variables" tab
  9. Click "New Variable"
  10. Name:  ANTHROPIC_API_KEY
      Value: sk-ant-api03-xxxxx (your actual key from Step 10)
  11. Click "Add"

  Also add:
  12. Click "New Variable" again
      Name:  CLIENT_URL
      Value: https://clothbuddy.vercel.app
             (we'll update this after Vercel deploy)
  13. Click "Add"

  14. Wait for Railway to finish deploying (1-2 minutes)
  15. Click "Settings" → find "Domains"
  16. Click "Generate Domain"
  17. COPY this URL — it looks like:
        https://clothbuddy-api.up.railway.app

  ✅ Your backend is live!

══════════════════════════════════════════════════════════
PHASE 9 — DEPLOY FRONTEND TO VERCEL (5 minutes)
══════════════════════════════════════════════════════════

──────────────────────────────────────────────────────────
STEP 16 — Update vercel.json with your Railway URL
──────────────────────────────────────────────────────────

  Open the file:  vercel.json  (in your clothbuddy folder)
  Find this line:
    "destination": "https://clothbuddy-api.railway.app/api/:path*"

  Replace it with YOUR Railway URL from Step 15:
    "destination": "https://YOUR-RAILWAY-URL/api/:path*"

  Save the file.

  Now upload this change to GitHub:
    git add vercel.json
    git commit -m "Update Railway URL"
    git push

──────────────────────────────────────────────────────────
STEP 17 — Deploy to Vercel
──────────────────────────────────────────────────────────

  1. Go to: https://vercel.com/dashboard
  2. Click "Add New..." → "Project"
  3. Find "clothbuddy" in the list → Click "Import"
  4. Framework Preset: Vite (should auto-detect)
  5. Click "Environment Variables" section
  6. Add:
     Name:  VITE_API_URL
     Value: (leave EMPTY — same-origin calls work automatically)
  7. Click "Deploy"
  8. Wait 2-3 minutes for it to build

  When done you'll see:  🎉 Congratulations!
  Click "Continue to Dashboard"
  Copy your URL — looks like: https://clothbuddy-xyz.vercel.app

  ✅ Your app is LIVE on the internet!

──────────────────────────────────────────────────────────
STEP 18 — Update Railway with your Vercel URL
──────────────────────────────────────────────────────────

  Go back to Railway:
  1. Click your project → Variables tab
  2. Find CLIENT_URL
  3. Change its value to your actual Vercel URL
     e.g. https://clothbuddy-xyz.vercel.app
  4. Save

SOMETHING WENT WRONG? — COMMON FIXES
══════════════════════════════════════════════════════════

  ❌ "npm: command not found"
  → Node.js didn't install properly. Restart your computer.
    Try installing again from nodejs.org

  ❌ "permission denied" on Mac
  → Add "sudo " before the command:  sudo npm install

  ❌ "git: command not found"
  → Git didn't install. Try the install again from git-scm.com
    Then restart Terminal.

  ❌ App loads but AI features don't work
  → Your API key might be wrong.
    Check Railway → Variables → ANTHROPIC_API_KEY
    Make sure it starts with "sk-ant-"

  ❌ "CORS error" in browser console
  → Check Railway → Variables → CLIENT_URL
    It must exactly match your Vercel URL (including https://)

  ❌ Blank white screen on Vercel
  → The build failed. Check Vercel dashboard → your project
    → Deployments → click the failed one → read the error logs

  ❌ "Cannot find module" error when running locally
  → You might have skipped npm install.
    Run:  npm install  then  cd server && npm install && cd ..
